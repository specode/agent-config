# session-ui 开发约定

## 定位

session-ui 是个人工作流的私人展示插件，优先为自己开发和个人当前实际使用的插件做定制化适配。当前不追求大众适配；未来可以独立发布，但不提前承担公共插件的兼容与配置成本。

## 适配范围

- 新增适配前核实本机实际启用的插件和接口，以当前个人需求为准。
- 可以针对明确的插件契约定制；不为未使用的插件、已停用的旧实现或假想用户添加兼容分支。
- 不因未来可能公开而提前引入通用插件发现、多版本协议或大而全的配置框架。

## 分层与边界

- 入口负责装配、配置与生命周期；具体适配逻辑负责外部插件契约到展示模型的转换；布局与渲染负责展示。
- 外部插件负责业务操作、请求策略、凭据和权威状态。session-ui 不复制其业务逻辑，不为展示重复获取数据，也不把推测显示为已确认结果。
- 将具体插件的数据解析与转换集中在明确边界，避免散落在多个 UI 模块中；纯逻辑优先使用无运行时依赖的单元测试。
- 分层是职责边界，不强制每层拆成独立文件。实现保持最小完整、可测试、可替换，不为抽象而抽象。
- 修改适配时同时检查生产者状态、转换逻辑、实际渲染和生命周期，避免单测通过但自定义 footer 不展示等集成遗漏。

## 演进与文档

- 为未来公共使用保留清楚的数据契约和模块边界，而不是现在兼容所有用户；实际准备公开时再评估配置泛化和对外兼容承诺。
- README 沿用中文；新增代码注释、命令描述及运行提示使用英文。
- 相关改动同步更新 README 和针对性测试，不顺手改造无关模块。
