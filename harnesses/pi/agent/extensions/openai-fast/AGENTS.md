# OpenAI Fast 开发约定

## 定位

本扩展面向公开、独立使用，不是个人状态栏的附属模块。当前源码暂存于配置仓库，但本目录应可单独取出安装和测试，不依赖父仓库安装脚本、兄弟目录或个人配置。

## 边界

- 通过 Pi 的标准扩展 API 和运行时配置目录工作，不硬编码用户目录、账号、模型白名单或私人插件接口。
- 默认关闭；配置、请求策略、认证判断归本扩展负责。明确区分插件允许尝试与后端实际支持。
- 只通过标准状态键 `openai-fast` 输出 `fast` 或清除状态；开启且适配时显示，其余情况隐藏。详细信息通过 `/fast status` 查询。
- 具体位置、颜色和布局归界面扩展决定，不导入 session-ui，也不为其复制或改写业务状态。
- 公开可用不意味着支持所有 provider：保持文档明确的 Codex OAuth 范围，不为假想需求过度抽象。
- 保留已有 service tier，不读取凭据文件，不新增隐式重试、降级、网络请求或费用估算。

## 文档与验证

- README 面向普通 Pi 用户，提供不依赖本仓库的安装、配置和测试说明；个人默认值和部署操作放在仓库文档，不写入公共使用契约。
- README 使用中文，代码注释、命令描述、运行提示和测试名称使用英文。
- 测试可从本目录独立运行，不需要账号、网络或其他扩展；真实后端支持不得用本地模拟测试冒充。
