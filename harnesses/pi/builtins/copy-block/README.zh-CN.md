# Copy Block

[English](./README.md) | [简体中文](./README.zh-CN.md)

Pi 扩展，通过 `/copy-block` 和 `Alt+C` 弹出交互式块选择器，直接从会话的原始 Markdown 源码复制代码块、引用块或完整助手回复——彻底避开终端边距、列表续行缩进、引用边框和软折行换行符。

## 快速开始

将目录复制到 Pi 的扩展目录：

```bash
cp -R /absolute/path/to/copy-block ~/.pi/agent/extensions/
```

在 Pi 中重新加载：

```text
/reload
```

## 使用说明

### 命令与快捷键

| 入口 | 作用 |
| --- | --- |
| `/copy-block` 或 `Alt+C` | 打开选择器并定位到最新一条助手回复 |
| `/copy-block N` | 定位到倒数第 N 条助手回复（`1` 为最新） |

### 选择器按键

| 按键 | 作用 |
| --- | --- |
| `↑` / `↓` 或 `k` / `j` | 上下选择 |
| `1`–`9` | 快速选中第 1–9 项 |
| `Enter` | 复制当前选中项到剪贴板 |
| `f` | 直接复制当前完整回复 |
| `e` | 在外部编辑器（`externalEditor` / `$VISUAL` / `$EDITOR`）中打开当前选中项 |
| `E` | 在外部编辑器中打开当前完整回复 |
| `←` / `→` 或 `h` / `l` 或 `[` / `]` | 切换到当前分支中更早 / 更新的助手回复 |
| `PgUp` / `PgDn` 或 `Ctrl+U` / `Ctrl+D` | 滚动预览区域 |
| `Esc` / `q` | 关闭选择器 |

说明：
- 自动提取围栏代码块（包括嵌套在有序/无序列表或引用块中的代码块，剥离外层容器缩进并保留代码本身缩进）、引用块以及完整原始回复。
- `e` / `E` 会打开一个临时草稿文件（编辑器退出后自动删除，修改不会写回会话），需要阻塞式编辑器命令（如 `nvim` 或 `code --wait`）。
